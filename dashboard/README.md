# dashboard/ — case study

Scrollable case study: Europe map, timeline, counterfactual chart, event study, placebo strip, exec
summary and methods appendix. It reads **only** the files in `dashboard/data/`, described below.
The page itself computes nothing.

## Data contract (`dashboard/data/`)

Generated by `analysis/dashboard_data.py` (`make dashboard`, part of `make all`) from
`data/processed/results/*.parquet`. **Never edit these files by hand.**

**Rules for every file**
- Top-level `status`: `"PROVISIONAL"` (some control stations still lack predictions) or
  `"FINAL"`. The page must show a visible PROVISIONAL banner unless every file says `"FINAL"`.
- Top-level `generated_utc`: ISO 8601, e.g. `"2026-10-06T03:04:39Z"`. It is the same in every file
  of one export, so mixed exports can be detected.
- Numbers are rounded to 2 decimals. GeoJSON coordinates have 3 decimals. Missing values are
  `null`.
- No prose, only short labels. Dates are `"YYYY-MM-DD"` and months `"YYYY-MM"`.
- Lists sit under `rows` (or a named key below), next to `status` and `generated_utc`.

**Units and signs**
- `ratio_pct` is observed / deweathered prediction − 1, in **percentage points**. Negative means
  less NO₂ than expected.
- `resid_ugm3` is observed − predicted, in **µg/m³**.
- `commute_excess` is ratio_pct over commuting hours minus ratio_pct over night hours, in
  percentage points.

### `meta.json`
```jsonc
{ "status", "generated_utc",
  "n_stations": { "DE": 284, "controls": 173, "by_country": { "AT": 53, ... } }, // traffic + background stations in the panel
  "n_station_days": 976897,
  "control_stations_with_predictions": 191, "control_stations_in_study": 587,  // all station types
  "control_countries": ["AT","BE","CH","CZ","FR","NL","PL"],
  "station_types": ["traffic","background"],
  "analysis_window": { "years": [2018,2019,2022,2023,2024,2025], "start": "2018-01-01",
                       "end": "2025-12-31", "excluded_years": [2020,2021] },
  "weather_grid_deg": 1.0 }
```

### `headline.json`
`rows`: one object per estimate.
```jsonc
{ "id": "nine_euro_primary", "label": "9-Euro-Ticket (Jun–Aug 2022)",
  "family": "primary" | "secondary (a)" | "secondary (b)" | "secondary (c)" | "heterogeneity"
            | "exploratory (ADR-009)",
  "outcome": "ratio_pct" | "resid_ugm3" | "commute_excess",
  "estimate", "ci_low", "ci_high",          // 95 % CI, two-way clustered
  "placebo_min", "placebo_max",             // placebo-country range of the same formula/outcome; null if none
  "verdict": "detected" | "not detected" | "not evaluated",
  "rule": "headline (ADR-008)" | "secondary outcome (ADR-010)" | "not applied",
  "direction": "higher" | "lower",          // sign of the estimate (NO₂ vs expected)
  "n_de", "n_ctrl" }                        // stations in the estimate
```
**Ids:**
- `nine_euro_primary`, `nine_euro_ugm3`;
- `switch_off`, `switch_off_atch`;
- `dticket`, `dticket_ugm3`;
- `persist_2024`, `persist_2024_trend`, `persist_2025`, `persist_2025_trend`;
- `classic_twfe`;
- `traffic`, `background`, `weekday`, `weekend`;
- `commute_excess_traffic`.

**Only `nine_euro_primary` carries the headline verdict.** `"detected"` means the ADR-008 rule
passed: the CI excludes 0 and the estimate lies outside the placebo range. It says nothing about
the sign, so always show `direction` next to it. `"not evaluated"` estimates must not be styled
as findings.

### `event_study.json`
`rows`: `{ "month": "YYYY-MM", "variant": "ref_janmay" | "season_adjusted", "est", "lo", "hi" }`,
the DE − controls gap in ratio_pct with its 95 % CI.
- 2018–2019 and 2022–2025 only. There is no 2020–21, so draw a gap, not a line, across it.
- `ref_janmay`: reference = mean of Jan–May 2022.
- `season_adjusted`: each month minus the same calendar month's 2018–19 average.

### `synthetic_control.json`
```jsonc
{ "variant": "raw", "outcome": "ratio_pct",
  "weights": { "AT": 0.15, ... },                        // donor weights, sum to 1
  "series": [ { "month": "YYYY-MM", "actual", "synthetic" } ],   // Germany vs synthetic Germany
  "rank_jun_aug_2022": 8, "rank_may_dec_2023": 3,        // post/pre RMSPE rank of DE; 1 = largest
  "n_units": 8 }                                         // smallest possible p-value = 1 / n_units
```

### `placebos.json`
```jsonc
{ "primary": [ { "outcome", "estimate", "lo", "hi" } ],   // the €9 estimate, both outcomes
  "rows":    [ { "kind": "country" | "date", "label", "outcome", "estimate", "lo", "hi" } ] }
```
- **Country placebos:** each control country as "treated", run on both outcomes. The label is
  the country code.
- **Date placebos:** fake policy windows in 2018–19, ratio_pct only. The label is the window.

### `map.json`
```jsonc
{ "value_unit": "...",
  "countries": [ { "cc", "name", "value_nine_euro", "value_dticket", "n_stations", "lat", "lon" } ],
  "stations":  [ { "id", "cc", "type": "traffic" | "background", "lat", "lon" } ] }
```
- **Country values are descriptive**: mean station-day ratio_pct, window minus reference, minus
  the same change in 2018–19. They have no SE and no verdict.
- `lat`/`lon` on a country is the centroid of its stations.
- `stations` are the stations used in the estimates.

### `timeline.json`
`rows`: `{ "id", "cc", "label", "category": "treatment" | "fuel_price" | "covid", "start", "end", "verified" }`.
- `end` is `null` for open-ended policies; COVID rows are single-day events (`start` = `end`).
- Covers the 9-Euro-Ticket, the Tankrabatt, the Deutschlandticket and its price steps, the German
  COVID end dates and the French remise carburant.
- Dates come from `warehouse/seeds/policy_calendar.csv`, where every row has a fetched source.

### `countries.geojson`
A FeatureCollection with `status`, `generated_utc` and `source` as foreign members, plus 12
features with properties `{ "ISO_A2", "NAME" }`:
- countries: DE, AT, BE, CH, CZ, FR (metropolitan), NL, PL, DK, LU, IT, ES;
- source: Natural Earth 1:50m, public domain (credit "Made with Natural Earth");
- simplified, ≤ 250 KB.

## Changing the contract
Change `analysis/dashboard_data.py` and this file in the same commit. Never rename a field
silently.
